## 搬瓦工支持支付宝吗？四种付款方式对比

支持。搬瓦工结账页有四种主要付款方式：支付宝、银联、PayPal 和信用卡。所有付款都由用户主动发起——搬瓦工不保存你的支付信息，也从不会自动扣款，这一点对用支付宝的人尤其重要，后面单独说。

四种方式放在一起比：

- **支付宝**：手机上有支付宝就行，扫码、确认，十几秒完成。系统按支付宝的汇率把美元账单折成人民币，确认前就能看到要付多少。
- **银联**：直接用国内银行卡走银联网络，也支持网银跳转和银联 App 扫码。不需要第三方账户，只是步骤比支付宝多几下。
- **PayPal**：多一层买家保护，出了纠纷可以走 PayPal 申诉，但需要先有已验证的账户。
- **信用卡**：Visa、MasterCard 都行。部分地区发的卡第一次支付可能被风控拦下，卡里有钱却被拒时，重试一次或换个方式通常就过了。

## 续费会不会自动从支付宝扣款

不会。搬瓦工不保存任何支付信息，技术上就做不到自动扣款——续费和首购一样，都得你自己主动付。机制是这样：套餐到期前 7 天，系统生成新账单并发邮件提醒，你有 7 天时间登录付款；超过这个窗口没付，服务会被暂停。

想省掉每次手动操作，可以往账户里预充值余额，系统会自动用余额抵扣后续账单。余额还是你自己充的，只是把“到期扫一次码”变成“提前充一次”。用支付宝续费就是重新走一遍扫码流程，和首购没有任何区别。
